### 01 // КОНЦЕПЦИЯ

**FORM // SYSTEM** спроектирован как бескомпромиссная инженерная альтернатива перегруженным коммерческим фитнес-трекерам.

* **Local-First архитектура (0 собственных серверов и телеметрии):** Вся база данных рациона, тренировочный дневник, веса и настройки хранятся исключительно на физическом устройстве пользователя. Проект не имеет проприетарного бэкенда, не требует регистрации учётной записи и не собирает пользовательскую аналитику.
* **Прямые клиентские интеграции по API:** Для работы ресурсоёмких модулей компьютерного зрения (оценка блюд по фото и чтение этикеток через **Gemini 3 Flash**) и каталога штрихкодов (**OpenFoodFacts**) клиент отправляет прямые защищённые запросы к соответствующим сервисам без промежуточных серверов.
* **Двухуровневое хранилище с защитой от сброса кэша:** В веб-среде данные сохраняются в `localStorage`. В нативной оболочке для iOS реализован двусторонний мост через `WKScriptMessageHandler`: при любом изменении состояние базы JSON и API-ключ синхронизируются напрямую в системный контейнер `UserDefaults` изолированной группы **App Groups** (`group.com.macro.shared`). Это защищает базу от автоматической очистки кэша WebKit операционной системой и обеспечивает моментальный доступ для нативных виджетов.
* **Интерфейс высокой информационной плотности:** Визуальная концепция выдержана в строгой эстетике швейцарского модернизма и брутализма — чистая монохромная типографика без эмоционального визуального шума и коммерческих баннеров.

### 02 // АРХИТЕКТУРА И МОДУЛИ

#### [ МАКРОНУТРИЕНТЫ И АДАПТИВНЫЙ МЕТАБОЛИЗМ ]
* **Адаптивный TDEE Engine (расход энергии):** Алгоритм отслеживает динамику утреннего взвешивания за 14 дней и сопоставляет её с калоражем потребления, вычисляя реальный суточный расход энергии (по аналогии с алгоритмами MacroFactor) для предотвращения метаболической адаптации на сушке или наборе.
* **Калькулятор целевого баланса:** Динамический расчёт BMR / TDEE с возможностью ручной фиксации целевого калоража и граммовок белков, жиров и углеводов.
* **One-Tap Stack (стек добавок):** Панель быстрого учёта ежедневного приёма нутрицевтиков и добавок (креатин, омега-3, витамины) в одно касание с фиксацией в общей базе.

#### [ AI-ЗРЕНИЕ И ОПТИЧЕСКИЙ МОДУЛЬ (GEMINI 3 FLASH + QUAGGA2) ]
* **AI-анализатор блюд и порций (Gemini 3 Flash Vision):** Мультимодальное компьютерное зрение с детекцией границ объектов (`object_box`), визуальной оценкой объёма готовых блюд на тарелке, расчётом примерного веса и автоматической раскладкой по КБЖУ.
* **Экспресс-распознавание этикеток:** Чтение таблиц БЖУ с упаковок и бутылок по фото с мгновенным занесением продукта в личную базу.
* **NLP-парсер рациона:** Распознавание свободного текстового ввода на естественном языке (*«250г гречки, 180г куриного филе и 15г оливкового масла»*) с автоматической калькуляцией макросов.
* **Аппаратный сканер штрихкодов:** Сканирование камерой в реальном времени на базе Quagga2 с мгновенным обращением к открытой базе OpenFoodFacts.

#### [ ТРЕНИРОВОЧНЫЙ ДВИЖОК И ГИПЕРТРОФИЯ ]
* **Сплит-архитектура (Д1–Д4):** Четырёхдневный цикл (Жим / Спина / Ноги / Плечи и Руки) с гибкой привязкой к дням недели и днями восстановления.
* **Учёт рабочих подходов:** Фиксация рабочих весов и повторений с автоматическим определением **лучшего рабочего подхода дня** (защита объективных силовых метрик от неизбежного спада повторений к 3–4 подходу из-за локального утомления).
* **Недельный мышечный объём:** Раздельный учёт рабочего объёма подходов по **5 мышечным группам** (Грудь, Спина, Ноги, Руки, Плечи) с визуальным контролем недельного лимита для предотвращения системной перегрузки ЦНС.
* **14-дневная аналитика прогрессии:** График прогрессии рабочих весов и повторений с алгоритмической детекцией силового плато.

#### [ СИСТЕМНАЯ ИНТЕГРАЦИЯ С iOS ]
* **WidgetKit Engine:** Нативный системный виджет для экрана «Домой» (iOS 17+), отображающий текущий остаток калорий, выполнение нормы белка и статус приёма ежедневного стека добавок.
* **App Groups Sync:** Мгновенный обмен данными между веб-движком и виджетом через изолированный системный контейнер `UserDefaults(suiteName: "group.com.macro.shared")`.
* **UserNotifications (умные пуши):** Планировщик локальных системных уведомлений на 14 дней вперёд. Интегрирован генератор персонализированных мотивационных фраз через Gemini по произвольному системному промпту пользователя.

#### [ АВТОНОМИЯ И РЕЗЕРВНОЕ КОПИРОВАНИЕ ]
* **Полный JSON-снапшот:** Экспорт всей локальной базы (история питания, каталог продуктов, силовые показатели, сплиты, стек добавок) в файл формата `.json` в один клик.
* **Мгновенное восстановление:** Импорт базы из файла для бесшовной миграции между устройствами без потери прогресса.

### 03 // РАЗВЁРТЫВАНИЕ И УСТАНОВКА

| Метод | Требования | Срок действия | Виджет iOS | Локальные пуши |
| :--- | :--- | :--- | :---: | :---: |
| **A. Сборка в Xcode (Эталон)** | Mac + Xcode + Apple ID | 7 дней / 1 год | **Да (100%)** | **Да** |
| **B. Progressive Web App (PWA)** | Safari / Chrome (без ПК) | **Бессрочно** | — | — |

*\*Примечание: При установке готового IPA через сторонние утилиты на бесплатный Apple ID расширение WidgetKit и общая память App Groups могут не связаться из-за ограничений бесплатных профилей подготовки. Для гарантированной работы виджета рекомендуется Метод A (Xcode).*

---

#### Метод A: Сборка из исходников в Xcode (Рекомендуется для iOS)
> Обеспечивает полную функциональность: нативный виджет на экране «Домой», локальные пуши и синхронизацию через App Groups.

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/paradoxiicalie/form.git
   cd form
   open form.xcodeproj
   ```
2. В Xcode выберите схему `form`.
3. В настройках целей `form` и `FormWidgetExtension` перейдите во вкладку **Signing & Capabilities** и укажите свою команду разработчика (*Team*).
4. Подключите iPhone кабелем (или по Wi-Fi через *Window → Devices and Simulators → Connect via network*).
5. Нажмите **Run** (`Cmd + R`) для компиляции и установки на устройство.

---

#### Метод B: Установка как Progressive Web App (PWA)
> Доступно на iOS (Safari) и Android (Chrome/Яндекс). Не требует компьютера и не подвержено ограничениям Apple.

##### Для iOS (Safari):
1. Откройте в **Safari** на iPhone официальный адрес:
   ```text
   https://paradoxiicalie.github.io/form/
   ```
2. Нажмите системную кнопку **«Поделиться»** (квадрат со стрелкой вверх в панели браузера).
3. Пролистайте меню вниз и выберите **«На экран "Домой"»**.
4. Нажмите **Добавить**.

##### Для Android (Google Chrome / Samsung Internet):
1. Перейдите по адресу `https://paradoxiicalie.github.io/form/` в Chrome на смартфоне.
2. Откройте меню браузера (**три точки** в углу) и нажмите **«Установить приложение»** (либо **«Добавить на главный экран»**).
3. Приложение инсталлируется в ОС как нативный пакет, запускается на весь экран без адресной строки и сохраняет данные в локальное постоянное хранилище.

---

#### Метод C: Установка готового IPA через Sideloadly
1. Соберите или загрузите скомпилированный файл `form.ipa`.
2. Подключите iPhone по кабелю к компьютеру и запустите **Sideloadly**.
3. Перетащите файл `form.ipa` в окно программы, введите ваш Apple ID и нажмите **Start**.
4. После завершения установки на iPhone перейдите в *Настройки → Основные → VPN и управление устройством* и подтвердите доверие профилю.

---

#### Метод D: Автономная переподпись на устройстве (SideStore)
1. Разместите файл `form.ipa` в файловой системе iOS (приложение «Файлы»).
2. Включите туннель WireGuard (SideStore VPN).
3. В приложении SideStore перейдите во вкладку **My Apps** → нажмите **`+`** → выберите `form.ipa`.
