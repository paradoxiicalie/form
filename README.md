### 01 // КОНЦЕПЦИЯ

**FORM** спроектирован как бескомпромиссная, строгая альтернатива перегруженным коммерческим фитнес-трекерам.

* **Без облачных бэкендов:** Данные не передаются на удалённые сервера и не зависят от чужой инфраструктуры.
* **Без подписок и рекламы:** Полный доступ ко всем модулям с первой секунды.
* **Без обязательной авторизации:** Вся база данных формируется и хранится строго в локальной памяти вашего устройства (`localStorage`).
* **Монохромная типографика:** Интерфейс построен по канонам швейцарского модернизма и брутализма — максимальная информационная плотность при полном отсутствии визуального шума.

### 02 // АРХИТЕКТУРА И МОДУЛИ

#### [ МАКРОНУТРИЕНТЫ И ЭНЕРГЕТИЧЕСКИЙ БАЛАНС ]
* **Расчёт целевых показателей:** Динамический расчёт BMR / TDEE с ручной корректировкой суточного калоража и баланса белков, жиров и углеводов.
* **Учёт фактического рациона:** Быстрый ввод продуктов, взвешивание граммовок, расчёт остатка суточного лимита.
* **Оптический модуль:** Встроенный сканер штрихкодов на базе компьютерного зрения (Quagga2) с прямым обращением к глобальному каталогу OpenFoodFacts.

#### [ ТРЕНИРОВОЧНЫЙ ДВИЖОК И ГИПЕРТРОФИЯ ]
* **Сплит-структура (Д1–Д4):** Четырёхдневная программа тренировок (Жим / Спина / Ноги / Руки и плечи) с возможностью свободной перепривязки к дням недели или назначения дней восстановления.
* **Фиксация рабочих параметров:** Учёт рабочих подходов, веса и повторений с сохранением персональных силовых ориентиров.
* **Контроль недельного мышечного объёма:** Визуализация суммарного тоннажа и количества подходов по целевым мышечным группам (грудь, спина, ноги, дельты/руки) для контроля системной усталости ЦНС.

#### [ СИСТЕМНАЯ ИНТЕГРАЦИЯ С iOS ]
* **WidgetKit Engine:** Нативный системный виджет для экрана «Домой» (iOS 17+).
* **Синхронизация через App Groups:** Мгновенный обмен данными между веб-контейнером и системным виджетом через изолированный `UserDefaults` (`group.com.macro.shared`).

#### [ АВТОНОМИЯ И РЕЗЕРВНОЕ КОПИРОВАНИЕ ]
* **Snapshot в JSON:** Полный снимок состояния базы данных (история питания, упражнения, веса, сплиты) скачивается в один клик.
* **Импорт базы:** Восстановление прогресса при смене устройства или переустановке без потери данных.

### 03 // РАЗВЁРТЫВАНИЕ И УСТАНОВКА

#### [ ПЛАТФОРМА: iOS ]

| Метод | Требования | Срок действия | Виджет iOS |
| :--- | :--- | :--- | :---: |
| **A. Progressive Web App (PWA)** | Safari (без ПК) | Бессрочно | — |
| **B. Sideload через Mac/ПК (iloader / Sideloadly)** | Кабель USB + Mac/ПК | 7 дней (автопродление утилитой) | Да |
| **C. On-Device подпись (SideStore / AltStore)** | WireGuard VPN на телефоне | Бессрочно (рефреш по Wi-Fi) | Да |
| **D. Сборка из исходников (Xcode)** | Xcode + Apple ID | 7 дней / 1 год | Да |

##### Метод A: Установка PWA через Safari (Рекомендуется для моментального старта)
> Не требует компьютера, сертификатов разработчика и не подвержен отзывам Apple.

1. Откройте в **Safari** на iPhone адрес:
   ```text
   https://paradoxiicalie.github.io/form/form/
   ```
2. Нажмите системную кнопку **«Поделиться»** в нижней панели браузера.
3. Выберите пункт **«На экран "Домой"»**.
4. Приложение запускается в полноэкранном standalone-режиме без элементов управления браузера и функционирует полностью оффлайн.

##### Метод B: Установка предсобранного IPA через iloader
1. Загрузите файл **`form.ipa`** из раздела [Releases](https://github.com/paradoxiicalie/form/releases).
2. Подключите iPhone по кабелю к компьютеру.
3. В интерфейсе **`iloader`** нажмите кнопку **`Import IPA`** и укажите скачанный файл.
4. На устройстве перейдите в *Настройки → Основные → VPN и управление устройством* и подтвердите доверие профилю разработчика.

##### Метод C: Установка без компьютера через SideStore
1. Поместите файл **`form.ipa`** в приложение «Файлы» (iCloud Drive / локально).
2. Активируйте VPN-туннель SideStore (WireGuard).
3. В приложении SideStore откройте вкладку **My Apps**, нажмите **`+`** и выберите `form.ipa`.

##### Метод D: Компиляция проекта в Xcode
```bash
git clone https://github.com/paradoxiicalie/form.git
cd form
open form.xcodeproj
```
В настройках целей `form` и `FormWidgetExtension` укажите команду разработки (*Signing & Capabilities*) и запустите сборку (`Cmd + R`).

#### [ ПЛАТФОРМА: ANDROID ]

##### Установка через PWA Standalone Engine
1. Откройте ссылку в **Google Chrome** или **Samsung Internet**:
   ```text
   https://paradoxiicalie.github.io/form/form/
   ```
2. Откройте меню браузера (`⋮`) и нажмите **«Установить приложение»** (либо **«Добавить на главный экран»**).
3. Подтвердите установку.
*Приложение инсталлируется в операционную систему как нативный пакет: запускается в изолированном окне без адресной строки, сохраняет данные в постоянное локальное хранилище и работает без подключения к сети.*
