## ⚡️ О проекте

**form** создан как бескомпромиссная альтернатива перегруженным платным фитнес-трекерам. Никаких назойливых подписок, рекламы, медленных облачных серверов и лишних кликов. Всё работает моментально, сохраняется исключительно на вашем устройстве и доступно в одно касание.

---

## ✨ Ключевые возможности

### 🍽 Питание и КБЖУ
* **Точный учёт макронутриентов:** Калории, Белки, Жиры, Углеводы в реальном времени.
* **Калькулятор целей:** Автоматический или ручной расчёт нормы калорийности под сушку, поддержание или набор массы.
* **База продуктов и блюд:** Быстрый поиск, добавление граммовок и кастомных рецептов.
* **Сканер штрихкодов:** Встроенный мгновенный поиск продуктов через камеру по международной базе данных OpenFoodFacts.

### 🏋️‍♂️ Тренировки и сплиты
* **Индивидуальный сплит (Д1–Д4):** Гибкая настройка тренировочных дней (Жим, Спина, Ноги, Плечи/Руки) с привязкой к дням недели.
* **Учёт рабочих подходов:** Фиксация веса, количества повторений, автоподстановка предыдущих рабочих весов.
* **Контроль недельного мышечного объёма:** Визуальные прогресс-бары рабочих подходов по ключевым мышечным группам (грудь, спина, ноги, руки/плечи) для предотвращения перетренированности.

### 📱 iOS Виджет (WidgetKit)
* Минималистичный интерактивный виджет для экрана «Домой».
* Мгновенно показывает текущий остаток калорий и прогресс по белку за день без необходимости открывать само приложение.
* Обмен данными через защищённый `App Group`.

### 🔒 100% Приватность и оффлайн
* Все ваши логи, приёмы пищи и веса хранятся **только на вашем устройстве** (`localStorage`).
* **Резервная копия в 1 клик:** Встроенный экспорт и импорт всей базы в формате `.json` (в «Файлы» или iCloud) для безопасного переноса между устройствами или обновления без потери прогресса.

## 📲 Установка

Приложение является кроссплатформенным и может использоваться как на **iPhone (iOS)**, так и на **Android** или в браузере.

---

### 🍏 Установка на iPhone (iOS)

Выберите любой удобный для вас вариант:

#### Вариант 1. Установка как PWA через Safari (Рекомендуется — без ПК, навсегда)
> Не требует компьютера, подписок разработчика Apple и никогда не отзывает сертификат!

1. Откройте веб-версию приложения в **Safari** на iPhone:
   ```text
   https://paradoxiicalie.github.io/form/form/
   ```
2. Нажмите кнопку **«Поделиться»** (квадрат со стрелкой вверх внизу экрана Safari).
3. Пролистайте вниз и выберите **«На экран "Домой"»**.
4. Нажмите **Добавить**.
*Приложение появится на рабочем столе как самостоятельная иконка. Запускается на весь экран без адресной строки браузера и работает оффлайн.*

---

#### Вариант 2. Установка через Mac/ПК (`iloader` или `Sideloadly`)
> Для тех, кому нужен нативный виджет iOS на экране «Домой».

1. Скачайте файл **`form.ipa`** из вкладки [Releases](https://github.com/paradoxiicalie/form/releases).
2. Подключите iPhone по кабелю к компьютеру.
3. Запустите утилиту **`iloader`** (или **`Sideloadly`**).
4. Нажмите **Import IPA** (или перетащите файл `form.ipa`).
5. Приложение подпишется вашим бесплатным Apple ID и установится на телефон за 10 секунд.
6. На телефоне: зайдите в *Настройки → Основные → VPN и управление устройством* и подтвердите доверие профилю.

---

#### Вариант 3. Установка без ПК через SideStore / AltStore
1. Установите **SideStore** на ваш iPhone.
2. Скачайте файл **`form.ipa`** в приложение «Файлы».
3. Включите VPN SideStore (WireGuard).
4. В SideStore перейдите во вкладку **My Apps** → нажмите **`+`** в верхнем углу → выберите `form.ipa`.

---

#### Вариант 4. Сборка из исходников в Xcode (для разработчиков)
1. Склонируйте репозиторий:
   ```bash
   git clone https://github.com/paradoxiicalie/form.git
   cd form
   ```
2. Откройте файл `form.xcodeproj` в Xcode.
3. В настройках целей `form` и `FormWidgetExtension` укажите свою команду разработчика (*Signing & Capabilities*).
4. Выберите ваш подключенный iPhone и нажмите **Run** (`Cmd + R`).

---

### 🤖 Установка на Android

Пользователи Android могут установить **form** в 1 клик без каких-либо магазинов приложений:

#### Способ: Установка как PWA (Google Chrome / Samsung Internet)
1. Откройте ссылку в браузере **Google Chrome** на телефоне:
   ```text
   https://paradoxiicalie.github.io/form/form/
   ```
2. Нажмите на меню браузера (**три точки** в правом верхнем углу).
3. Выберите пункт **«Установить приложение»** (или **«Добавить на главный экран»**).
4. Подтвердите установку.
*Приложение появится в общем списке приложений и на рабочем столе. Оно функционирует как полноценное нативное приложение Android, поддерживает работу без интернета и сохраняет всю историю локально.*

## 🛠 Стек технологий

* **Frontend / UI:** Vanilla JavaScript (ES6+), HTML5, Tailwind CSS, Quagga2 (сканирование штрихкодов), Google Fonts (Inter, JetBrains Mono).
* **iOS Native Shell:** Swift 5, SwiftUI, WebKit (`WKWebView`), UserActivity.
* **iOS Widgets:** WidgetKit, App Groups (`UserDefaults`), TimelineProvider.
* **Storage:** LocalStorage (с поддержкой импорта/экспорта в JSON).
