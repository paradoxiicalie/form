# FORM // System — Project Instructions & Rules

## 1. Автономный режим выполнения (Autonomous Mode) — КРИТИЧЕСКОЕ ПРАВИЛО
- **НИКОГДА не спрашивать пользователя о промежуточных действиях** и **НЕ вызывать интерактивные модальные опросы** (`ask_question` / выбор вариантов).
- Пользователь полностью доверяет работу агенту: задача должна выполняться «под ключ» от начала до конца автономно без ожидания подтверждения.
- Агент самостоятельно принимает наилучшие инженерные и дизайн-решения, проводит валидацию, собирает проект и пушит изменения в git.

## 2. Архитектура и файлы проекта
- Проект объединяет iOS-приложение на SwiftUI (`form.xcodeproj`) и веб/PWA-версию (`index.html`).
- **Синхронизация HTML:** Корневой файл `index.html` (для GitHub Pages / PWA) и внутренний файл `form/index.html` (ресурс приложения внутри Xcode) **ОБЯЗАНЫ быть на 100% идентичными**. После любых правок в одном файле всегда синхронизировать второй (`cp index.html form/index.html`).
- **Песочница терминала:** При выполнении shell-команд в директории репозитория запускать команды с `BypassSandbox: true`, так как доступ к глобальному `.gitconfig` и Xcode SDK требует выхода за пределы изолированной песочницы.

## 3. Сборка и валидация
- Перед коммитом и пушем проверять сборку Xcode:
  ```bash
  xcodebuild -project /Users/alexeytikunov/xcode/form/form.xcodeproj -scheme form -destination 'generic/platform=iOS' build CODE_SIGNING_ALLOWED=NO
  ```
- Проверять отсутствие расхождений между HTML-файлами:
  ```bash
  diff -u form/index.html index.html
  ```
- Изменения коммитить и пушить в ветку `main` репозитория.
